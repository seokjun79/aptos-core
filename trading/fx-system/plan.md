# FX 트레이딩 시스템 (석준님 지시, 2026-11-09)

목표: 외환(FX)만 다루는 트레이딩 시스템. 시험 한 번 하고 "불합격"으로 멈추지 않는다.
매일 돌면서 매주 고쳐 버전을 올린다.

## 대상
- GBPUSD, EURUSD, XAUUSD, GBPJPY. RC가 이미 차트로 보는 4종목이다.
- 시간봉은 4H CRT 기준이고, 진입은 15분과 1시간 봉으로 본다.
- 석준님 방식은 `trading/rules/smc-crt-analysis.md`를 따른다.

## 지난 FX 17개가 진 이유 → 이번 설계에서 막는 방법
1. 비용(스프레드·스왑)이 이득보다 컸다.
   - 그날 안에 정리하는 거래만 한다(스왑 0).
   - 예상 움직임이 비용의 3배 미만이면 거래하지 않는다.
2. 한 구간에서 좋던 조합이 다음 구간에서 무너졌다.
   - 규칙은 매주 하나만 바꾼다.
   - 판정은 학습에 안 쓴 기간(전진 기록)으로만 한다.
3. 신호가 너무 적거나 너무 많았다.
   - 하루 0~3건이 되게 거른다.

## 부품
1. **자료**
   - MT5에서 4종목의 M15·H1·H4를 매시간 받는다(RC, 이미 15분 갱신 중).
   - 경제지표 일정도 같이 받는다.
2. **규칙 엔진 (석준님 SMC+CRT)**
   - CRT 스윕, MSS 몸통 마감, OB·FVG 되돌림을 코드로 자동 판별한다.
   - 후보 자리마다 진입·손절·목표·손익비를 계산한다.
3. **AI 필터 (qlib, LightGBM → 딥러닝)**
   - 후보 자리마다 "목표 먼저 닿을 확률"을 예측한다.
   - 재료: 세션 시간, 변동성, H4·일봉 방향, 스윕 깊이, 지표 발표까지 남은 시간 등.
   - 확률이 높은 자리만 통과시킨다.
4. **위험 관리**
   - 1회 위험은 계좌의 0.5%다.
   - 하루 −3%면 그날은 잠근다.
   - 큰 발표 30분 전후에는 진입하지 않는다.
5. **실행**
   - 처음에는 주문 없이 전진 기록만 한다(데모 계좌는 쓰지 않는다).
   - 실전 주문은 석준님 승인 뒤에만 켠다.
6. **학습 반복 (매주 금요일)**
   - 진 거래를 뜯어본다.
   - 가설 하나를 고쳐 다음 버전에 넣는다.
   - "지난주보다 무엇이 나아졌나"를 숫자로 보고한다.
   - 학습 일지: 가설 → 결과 → 왜 → 다음.

## 가져다 쓸 방법: day-trader-skill (석준님 지시, 2026-11-09)
원본 설명서는 `tools/vendor/day-trader-skill/`에 있다(MIT, 코드는 안 가져옴).
미국 주식 전용이라 코드는 그대로 쓰지 않는다. 아래 4가지 방법만 RC2가 FX용으로 새로 짠다.
1. **타임머신(제일 중요)**
   - 원본: 진입·손절·목표가 정해지면, 그 종목의 최근 60일 5분봉 중 같은 시간대 봉을 섞어 남은 장을 1만 번 다시 돌린다.
   - 결과로 "목표 먼저 / 손절 먼저 / 둘 다 아님" 비율을 낸다.
   - 같은 규칙이 과거에 나온 날을 전부 다시 돌린 실제 기록도 함께 보여 준다.
   - FX 판: MT5 M5 자료를 쓴다(RC가 꺼냄).
   - 세션은 런던(서버 10~18시)과 뉴욕(서버 15~23시)으로 나눈다.
   - 같은 시각 ±2봉에서 뽑는다.
   - 손절과 목표가 한 봉 안에 같이 닿으면 손절로 친다(보수적).
   - 스프레드는 뺀다.
   - 판정 문구는 원본과 같다: 손익비 R에서 본전 확률은 1/(1+R).
2. **위험 점검표 (PASS/BLOCK)**
   - 1회 위험 0.5%, 하루 −3% 잠금, 손익비 1:2 미만, 발표 30분 전후, 하루 3건 초과를 막는다.
   - 하나라도 걸리면 BLOCK이고, 이유를 적는다.
3. **크기 계산**
   - 계좌·1회 최대 손실·손절 핍으로 랏을 계산한다(0.01랏 단위).
   - 반올림으로 위험이 커지면 내려서 잡는다.
4. **순서대로 넘기는 파일**
   - 순서: 엔진(자리 찾기) → plan.json → 타임머신 → 크기 → 위험 점검 → 기록.
   - 주문 단계는 만들지 않는다. 실전은 석준님 승인 뒤에 따로 정한다.

- 11/12: 엔진이 찾은 자리마다 타임머신 결과를 AI 필터 재료로 넣는다.
