## 실전 위험
1. 잔고 $16, 0.01랏 고정: 손절 폭이 보통 8~20핍이라 1회 손실이 $0.8~2.0 = **잔고의 5~12%**. 5연패면 40~60%.
   InpUseRiskLot=true여도 260행 `MathMax(mn, …)`가 랏을 0.01로 다시 올려서 소용없음.
   → 계산 랏 < 최소 랏이면 진입 안 함, 손절 폭 상한 추가.
2. 391행: 포지션 보유 중 다른 모델의 스윕 극값·무효 판정이 갱신되지 않음 → 손절이 너무 좁게 잡히거나 무효 셋업 진입. → 검사를 400행 뒤로.
3. 289~297행: 지정가가 GTC이고 재시작 시 pendTicket 복원 안 됨 → 늦은 체결 가능. → 만료 시각 지정 + OnInit 복원.
4. 509~515행: 강제 청산이 XE~XE+10분 사이 틱에만 실행. → `m >= XE`면 청산.
