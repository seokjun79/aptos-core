# 석준님 매매 학습 자료

석준님이 녹화한 실시간 매매 영상과 MT5 기록을 모아, 석준님 방식(SMC+CRT)을 매니저 비너스가 배우는 곳이다. 목표는 20~30건이다.

## 자료 받는 법
- 영상: Google Drive "비너스 매매 학습" 폴더에 올리면 매니저가 내려받아 장면을 뽑는다(ffmpeg로 10초마다 1장 + 큰 움직임 장면).
- 차트 캡처: 대화창에 바로 보내도 된다.
- MT5 기록: RC비너스가 VenusCRT_journal.csv와 주문 내역을 읽기만 해서 보낸다.

## 거래 한 건 = 카드 한 장 (`trades/YYYYMMDD-종목-번호.md`)
| 항목 | 내용 |
|---|---|
| 종목·방향·시간 | 서버 시간, 한국 시간 |
| 4H CRT 기준봉 | CRH / CRL, 어느 봉 |
| 스윕 | 어느 쪽, 어디까지, 4H 마감이 범위 안인지 |
| HTF 위치 | 4H OB·FVG·유동성 |
| MSS | 석준님이 그은 선, 몇 분봉, 몸통 마감 시각 |
| 진입 | 진입 OB/FVG, 주문 종류, 가격 |
| 손절·목표·손익비 | 가격과 핍 |
| 결과 | 체결 여부, 손익, 걸린 시간 |
| 석준님 말 | 영상 속 설명 그대로 |
| 매니저 판단과 차이 | 매니저가 같은 차트에서 다르게 본 점, 누가 맞았는지 |
| 배운 점 | 규칙으로 옮길 한 줄 |

## 규칙에 반영
배운 점이 3건 이상 같은 방향이면 `trading/rules/smc-crt-analysis.md`에 반영하고 석준님께 보고한다.
