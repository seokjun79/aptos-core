# 프로젝트 2 ICT 2차: 바이어스 규칙 (미리 정함, 2026-10-29)

이 문서가 `trading/research/ict_bias.py`의 규칙 원문이에요. 코드 맨 위 설명과 같은 내용이에요.
**실제 데이터를 돌리기 전에 고정했어요(실제 데이터는 석준님 PC에만 있고, 만든 쪽은 결과를 못 봐요).** 결과를 보고 바꾸지 않아요.
바꾸면 새 날짜로 새 규칙을 따로 적고, 시험한 수에 더해요.

왜 하나: 1차(56개 변형) 결과 합격 0. 그런데 "양봉으로 끝난 날의 89%는 뉴욕 10시 전에 자정 시가 아래로 먼저 내려갔다"(전체 날은 61%).
→ ICT 진입 자리에는 우위가 없고, 우위가 있다면 **오늘 오를지 내릴지(일일 바이어스)를 맞히는 능력**에서 나와야 해요.
2차는 두 가지를 물어요. **A: 바이어스가 몇 % 맞아야 본전인가? B: 미리 알 수 있는 규칙 중 그만큼 맞히는 것이 있는가?**

## 공통 (1차 `rules.md`와 같음)
- 시각은 모두 뉴욕(NY). MT5 서버 = NY + 7시간. 한국시간 = NY + 13(서머타임) / + 14.
- 데이터·비용·체결 규칙·ICT 단위 u(= ADR20 ÷ 7)·IS/OOS 나누기는 1차와 같아요. 코드도 `ict_backtest.py`(커밋 a2d7682, SHA256 629772f3…017c)를 그대로 불러 써요.
- 비용: 스프레드 기본 1핍(금 0.2달러 = 2핍), 거래당 1번 뺌. 같은 봉 손절 우선, 체결 봉 목표 무시, 갭 손절은 시가.
- IS = 2019-01-01 ~ 2023-12-31, OOS = 2024-01-01 ~ (거래일 날짜 기준).

## 오늘의 방향(정답) 정의 — 하나로 고정
- **방향 = NY 16:00 종가(서버 22:55 M5 봉 종가) − 자정 시가 MO(NY 00:00 = 서버 07:00 봉 시가)의 부호.** + = 상승일, − = 하락일, 0 = 제외.
- 이유: Power of 3 거래와 1차의 89% 통계가 모두 이 구간(자정 → 16시)을 써요. 서버 D1(NY 17시 ~ 17시)은 거래 시작 7시간 전에 열려 맞지 않아요.
- 쓰는 날(유효일): 거래일 인덱스 ≥ 21(ADR20 있음), 아시아 범위 봉 30개 이상, 자정 뒤 11시 전 봉 있음,
  그날 마지막 봉이 NY 13:00 이후(일찍 닫는 휴일·잘린 날 제외). 정답 비교에는 방향 ≠ 0인 날만.

## A: 정답을 알면 얼마나 버나 — 손익분기 정확도
### 거래 모델 5개 (진입·손절은 1차 그대로, 매도는 완전 대칭)
| 이름 | 진입 | 손절 | 청산 |
|---|---|---|---|
| PO3-2R | 자정~11시, MO − 1u 매수 지정가 (1차 M2-MO-PO3) | 진입 − 2u | 목표 2R(4u), 아니면 NY 16:00 |
| PO3-T11 | 같음 | 같음 | 목표 없음, NY 11:00 직전 봉 종가 |
| PO3-T16 | 같음 | 같음 | 목표 없음, NY 16:00 직전 봉 종가 |
| BRK-2R | 좁은 아시아 범위(≤ 0.4 ADR20), 자정 뒤 AR 저가가 먼저 깨진 뒤 AR 고가에 매수 스톱 (1차 M2-ASIA-BRK) | 그때까지 최저가 − 1핍(최소 1u) | 목표 2R, 아니면 NY 16:00 |
| BRK-T16 | 같음 | 같음 | 목표 없음, NY 16:00 |
- 날마다 매수 공간·매도 공간 거래를 각각 따로 계산해 둬요(없을 수도 있음). 한 날 한 모델 최대 1거래, 그날 안에 청산 → 겹침 없음.
- 바이어스 b = +1이면 매수 거래, −1이면 매도 거래, 0이면 거래 없음.

### 정답 섞기
- 맞은 쪽 거래 = 그날 실제 방향 쪽 거래(R합 Sc, 건수 Nc). 틀린 쪽 = 반대 방향 거래(Sw, Nw).
- 바이어스가 확률 p로 맞으면 기대 평균 R(p) = (p·Sc + (1−p)·Sw) ÷ (p·Nc + (1−p)·Nw). (계산식, 정확)
- **손익분기 p\*** = Sw ÷ (Sw − Sc) (Sc > 0 > Sw일 때). Sc ≤ 0이면 "정답을 알아도 손해 → p\* 없음". Sw ≥ 0이면 바이어스 없이도 + (p\* ≤ 0.5로 표시).
- p = 0.50, 0.55, …, 1.00. 확인용 몬테카를로: 날마다 확률 p로 맞음/틀림을 뽑아 200번(시드 고정) → 평균 R의 5%·50%·95%.
- 종목별 · 9종목 합계, IS · OOS · 전체로 표를 내요. **B의 관문에 쓰는 p\*는 "9종목 합계 IS" 값 하나**(모델마다).

## B: 미리 알 수 있는 바이어스 규칙 15개 (모두 NY 00:00 전에 정해짐)
- 판단 시점 = 서버 07:00 봉 직전. 쓰는 정보: 완성된 서버 일봉(전날 D−1까지), 완성된 지난주, 그날 서버 00:00~07:00 봉(NY 17~24시).
- 현재가 P = 서버 07:00 직전 봉 종가. PDH/PDL = D−2 일봉 고·저(= D−1 입장에서 '전날'), PD = D−1 일봉.

| # | 이름 | 규칙 (+1 = 오늘 상승 예측, −1 = 하락, 0 = 판단 없음) |
|---|---|---|
| P0 | PH1-B | 1차 바이어스 B: 지난주 종가 vs 그 전 주 중간, D−1 종가 vs D−2 중간. 둘이 같으면 그 방향 (비교 기준) |
| P1 | PD-CE | D−1 종가 > D−1 범위 중간이면 +1, < 이면 −1 |
| P2 | PD-RULE | ICT 일봉 규칙: D−1이 PDH를 넘고 종가 > PDH → +1, 넘었는데 종가 ≤ PDH → −1(되돌림). PDL은 거울. 둘 다 넘으면 종가가 PDH 위 +1 / PDL 아래 −1 / 사이 0. 둘 다 안 넘으면 0 |
| P3 | SWEEP-LAST | D−1 안에서 PDH·PDL 중 **마지막에 쓸린 쪽의 반대**(고가 쪽이 마지막 → −1). 한쪽만 쓸렸으면 그 반대. 같은 M5 봉에서 둘 다 처음이면 0 |
| P4 | CLOSE-LOC | D−1 종가가 D−1 범위 위 25% 안 → +1, 아래 25% 안 → −1, 가운데 0 |
| P5 | WEEK-DRAW | 지난주 고가 PWH·저가 PWL 중 이번 주(지금까지) 아직 안 깨진 쪽으로. 둘 다 안 깨졌으면 P에서 더 가까운 쪽. 둘 다 깨졌으면 0 |
| P6 | DAILY-FVG | 최근 60일 일봉 FVG(상승: 봉 k 저가 > 봉 k−2 고가, 하락: 봉 k 고가 < 봉 k−2 저가) 중 생긴 뒤 CE(중간)까지 안 닿은 것. P 위에 있는 것과 아래 있는 것 중 더 가까운 쪽으로. P가 FVG 안이면 그 FVG는 제외 |
| P7 | WEEK-OPEN | P > 이번 주 시가(서버 월요일 첫 봉 시가) → +1, < → −1 (주간 Power of 3) |
| P8 | MT-EXTREME | 수·목·금만: 이번 주 완성된 날 중 최저가가 월·화에 나왔고 최고가가 그 뒤 날이면 +1, 최고가가 월·화이고 최저가가 그 뒤 날이면 −1. 월·화·그 밖 0 |
| P9 | ASIA-PD | 아시아 범위(NY 19~24시) 중간 > D−1 범위 중간(프리미엄) → −1, < (디스카운트) → +1 |
| P10 | EMA20 | 일봉 종가 EMA20 기울기(D−1 값 − D−2 값)의 부호 (기준선, ICT 아님) |
| P11 | RET5 | D−1 종가 − D−6 종가의 부호 (기준선, ICT 아님) |
| C1 | RULE+WEEK | P2와 P5가 같은 방향일 때만 그 방향 |
| C2 | WEEK+FVG | P5와 P6이 같은 방향일 때만 |
| C3 | RULE+WEEK+WO | P2·P5·P7 셋이 모두 같은 방향일 때만 |

### 적중률 측정
- 유효일 중 예측 ≠ 0이고 방향 ≠ 0인 날: 적중률 h = 맞은 날 ÷ 예측한 날. 종목별·9종목 합계, IS·OOS.
- 검정: t = (h − 0.5) ÷ √(0.25 ÷ n). **Bonferroni(한쪽 5%, 규칙 15개) → t ≥ 2.71**.
- 참고 열: 예측 비율(커버리지), 상승일 비율, "상승일 비율만으로 기대되는 적중률"(예측이 +에 치우친 규칙이 추세장에서 공짜로 얻는 몫)과 그 대비 z.

### 관문 → 실제 거래
- **관문 통과 = 9종목 합계 IS 적중률 > p\*(그 모델) 그리고 9종목 합계 OOS 적중률 > p\*(같은 값).** p\*가 없는 모델은 아무도 통과 못 해요.
- 통과한 (규칙, 모델) 쌍만 정식 판정: 그 규칙을 바이어스로 실제 거래(정답 안 씀).
- 판정 기준(README 그대로): OOS 60건 이상 · OOS 평균 R > 0 · OOS PF ≥ 1.2 · IS 평균 R > 0 · 종목 과반 IS·OOS 둘 다 + · 연도 과반 + ·
  **IS t ≥ Bonferroni(한쪽 5%, 규칙 15 × 모델 5 = 75쌍 → 3.21, 관문 통과 수와 무관하게 고정)** · 랜덤워크 2개(스프레드 0) t < 2.
  모두 통과 = 합격, 아니면 IS·OOS 평균 둘 다 + 면 후보(실전 권유 안 함), 그 밖은 불합격.
- 관문을 못 넘은 쌍도 거래 성적은 `partB_trades_all.csv`에 "참고"로 남겨요(판정 대상 아님, 고르는 데 쓰면 과최적화).

## 해석할 때 주의 (실데이터 보기 전에 적어 둠)
- A는 "정답을 안다"는 불가능한 가정이에요. p\*는 "이만큼은 맞혀야 한다"는 바닥선일 뿐, 그 정확도면 번다는 보장이 아니에요
  (맞히는 날이 큰 움직임 날인지 작은 날인지에 따라 실제 R은 달라요 → 그래서 B에서 실제 거래로 다시 확인).
- 적중률은 모든 유효일 기준, p\*는 거래가 난 날 기준이라 둘이 정확히 같은 모집단은 아니에요.
- 15개 규칙을 시험하면 우연으로 1~2개는 t 2 근처가 나올 수 있어요. 그래서 Bonferroni 2.71과 OOS 확인을 둬요.
- 예측이 한쪽(+)에 몰린 규칙(P5·P7·P10 등)은 그 기간이 추세장이면 적중률이 공짜로 올라가요. "상승일 비율 기대 적중률" 열과 같이 봐요.
- 석준님 본인의 바이어스 판단도 같은 정의(자정 시가 → NY 16시 종가)로 기록하면 p\*와 바로 비교할 수 있어요(`daily_bias_table.csv`).
