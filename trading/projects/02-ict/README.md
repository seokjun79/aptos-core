## 합격 기준 (미리 정함, 2026-10-29)
- 비용 포함(스프레드 최소 1핍, 금 0.2달러), 같은 봉 손절 우선, 미래 정보 사용 금지
- IS = 2019-01-01 ~ 2023-12-31, OOS = 2024-01-01 ~
- 변형 선택은 IS로만. OOS는 마지막에 한 번 본다
- 합격: OOS 거래 60건 이상, OOS 평균 R > 0이고 PF ≥ 1.2, IS도 평균 R > 0, 종목 과반에서 IS·OOS 모두 +, 연도 과반 +, 시험한 변형 수로 Bonferroni 보정한 t 기준 통과, 랜덤워크 데이터에서는 엣지가 0 근처
- 하나라도 못 넘으면 "후보"로만 적고 실전 권유 안 함
