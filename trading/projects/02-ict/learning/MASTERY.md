# ICT 숙지 계획 — 백테스트보다 먼저 (석준님 지시, 2026-10-29)

석준님 지시: "학습하라고 한 영상들을 비너스가 숙지하는 것이 우선." 숙지했다는 증거가 나오기 전에는 백테스트를 하지 않는다.

## 지금까지의 문제 (인정)
- 자막 글자만 읽었고 화면(차트)은 보지 않았다. ICT는 차트를 가리키며 "여기, 이거"라고 설명하므로 글자만으로는 반쪽 학습이다.
- 영상별 메모는 RC가 만든 요약이다. 매니저는 원문 전체를 처음부터 끝까지 읽지 않았다(LPOaFOZekf8 하나만 원문 전체를 읽음).
- 모르는 부분을 추측으로 채워 규칙을 만들고 바로 백테스트했다.

## 숙지 방법 (영상 하나씩, 순서대로)
1. **원문 전체 읽기** — 자막을 처음부터 끝까지 읽는다. 요약본으로 대신하지 않는다.
2. **화면 보기** — ICT가 "여기, 이 캔들, 이 갭"이라고 말하는 시각마다 영상 화면을 캡처한다(RC가 PC에서 캡처, 매니저와 RC가 그림을 직접 본다). 어떤 캔들·어떤 선인지 그림으로 확인한다.
3. **개념 사전** — 개념마다 ICT 본인 말로 정의 + 근거 시각(예: [12:20]) + 화면 캡처. 영상끼리 정의가 다르면 둘 다 적는다.
4. **ICT 매매 예시 재구성** — 영상 속 매매를 "몇 시 → 무엇을 보고 → 어디서 진입 → 손절 → 목표 → 왜" 순서로 다시 쓴다. 화면과 글이 맞아야 한다.
5. **모르는 것 목록** — 영상에서 확인이 안 되는 것은 추측하지 않고 "모름"으로 남긴다.

## 숙지했다는 증거 (통과 기준)
- **A. 시험:** 매니저가 아닌 다른 담당(reviewer)이 원문 자막과 화면만 보고 문제 40개를 낸다. 비너스는 원문을 보지 않고 답한다. reviewer가 채점해서 **90% 이상**이어야 통과한다.
- **B. 따라 그리기:** ICT가 가격과 시각을 말한 예시(예: 29,053 / 29,137 / 30,397.75 / 29,483 @14:43 / 지난주 범위 0.35)를 차트 데이터에서 똑같이 찾아 그린다. 숫자가 맞아야 통과한다.
- **C. 석준님 확인:** 개념 사전과 예시 재구성 중 석준님이 아무거나 골라 물어보면 근거 시각과 화면으로 답한다.
- A·B·C를 모두 통과한 개념만 규칙으로 만들고, 그다음에 백테스트한다.
- **석준님 지시(2026-10-29): "완벽하게 알 때까지 반복 시청."** 시험 통과선은 100%로 올린다. 100%가 아니거나 시험관이 약점을 지적하면 그 구간을 다시 보고(재시청·재캡처) 숙지 문서를 보강한 뒤, 새 문제로 다시 시험한다. 100%와 적용 시험 통과까지 반복한다.
- 시험관: 자막 원문 전체는 저작물이라 PC 밖(저장소·메시지)으로 옮기지 않는다. 그래서 PC 안의 별도 Claude 창(시험관)이 원문과 화면만 보고 문제를 내고 채점한다. 시험관은 숙지 문서를 보지 않는다.

## 답안 원칙 (2026-10-29, 7번 영상 1차 불합격 뒤 추가)
- **이 영상에서 직접 말한 것만 답한다.** 영상에 없는 일반 ICT 지식(NWOG, IPDA 등)으로 빈칸을 채우지 않는다. 영상에 없으면 "영상에 없음"이라고 쓴다.
- **반어인지 직설인지는 문장마다 따로 판정한다.** 6번 영상의 "probably random"(반어)을 배웠다고 7번 영상의 "coincidence"(직설: 17·20·40분은 매크로가 아니다)까지 반어로 읽으면 틀린다.
- 숫자만이 아니라 ICT가 "왜"라고 말한 이유 문장을 숙지 문서에 원문 인용과 시각으로 남긴다.
- **화면 숫자는 계산으로 채우지 않는다.** 화면 라벨(OHLC 헤더, 옥턴트 라벨, 툴팁)은 원값 그대로 [V]로 적는다. 계산값과 라벨값이 다를 수 있다(8번 영상 1차 불합격 원인).
- **기억이 안 나면 "기억 안 남"으로 쓴다. 지어내지 않는다.** (8번 영상 Q17 IFVG 세 특징을 지어내 0점)
