## 금 야간 — MT5 실제 틱 테스트 (2026-10-22, XAUUSD H1, 2022-01 ~ 2026-10, 히스토리 품질 99%)

설정: 스프레드 60포인트($0.60) 넘으면 진입 미룸, 진입 지연 0분, InpMaxLots 0.01(고정 0.01랏으로 돌았음).
결과: 446건, 승률 46.4%, PF **1.02**, 순익 +$32.5 (0.01랏 기준).
연도별 거래: 2022 258건 / 2023 156건 / **2024·2025 0건** / 2026 32건.

해석:
- 2024~2025에 진입이 아예 없음 → 재개장 시간(뉴욕 18시)의 **실제 스프레드가 $0.60을 계속 넘었다**는 뜻. H1 봉 spread(최솟값)는 실제 비용을 과소평가했음.
- 거래가 된 구간에서도 PF 1.02로 본전 수준.
다음: 스프레드 제한 해제(1000포인트)로 실제 비용 그대로 측정 + 진입 30분 지연 비교.
