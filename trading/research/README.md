### 쉬운 말 용어
- **R**: 손절 한 번 크기. +2R = 손절폭의 2배를 벌었다는 뜻. 기대값 +0.1R = 거래마다 평균 손절폭의 10%씩 번다는 뜻.
- **IS / OOS**: 2024-01-01 전(IS)은 "고르는 기간", 그 뒤(OOS)는 "확인하는 기간". IS에서 좋았던 조합이 OOS에서도 +여야 믿을 수 있어요.
- **t값**: 2보다 작으면 "운과 구분이 안 됨".

### 정의 (EA `VenusCRTAssistant.mq5`와 맞춤)
1. C1 = 직전 마감 4H봉(서버시간 0·4·8·12·16·20시 시작). C2 = 다음 4H봉. C2 동안 15분봉 저가가 CRL 아래면 스윕(먼저 나간 쪽 하나만).
   기본은 C2가 CRL~CRH 안에서 마감해야 성립. C2가 뉴욕 19시~2시에 시작하면(아시아장) 제외(`--include-asia`로 포함).
2. MSS 선 = EA `TrueMssLevel`과 같음: 스윕 극값 봉에서 거꾸로 가며 처음 만나는 15분봉 스윙 고점(왼쪽 N봉보다 높고 오른쪽 N봉 이상),
   CRH 이상은 건너뜀, C1에서 CRL을 만든 봉 이후만 봄. 극값이 새로 낮아지면 다시 계산. 확정 = 15분봉 양봉 종가가 MSS 선 위 + 종가가 범위 안. C2 안에서만 찾음.
3. OB = 확정 봉 바로 앞에서 극값 봉까지 거꾸로 가며 처음 만나는 음봉.
4. 주문 시각 = 확정 봉 마감과 C2 마감 중 늦은 쪽(C2 마감을 확인한 뒤에만 주문 → 미래 엿보기 없음). 그 사이 CRH에 먼저 닿으면 취소.
   유효시간 16봉(4시간) 안에 안 닿으면 취소. 체결 전에 CRH에 닿아도 취소. 지정가가 현재가보다 불리하면(매수인데 위) 건너뜀.
5. 체결·청산은 5분봉. 같은 5분봉에 손절·목표 둘 다 → 손절. 체결한 5분봉에서는 목표 인정 안 함. 스프레드: 매수는 ask(=bid+스프레드)로 체결.
   갭으로 손절을 건너뛰면 시가로 청산(−1R보다 나쁠 수 있음). 보유 시간 제한 없음(`--max-hold-bars`로 설정 가능). 데이터 끝까지 안 끝난 거래는 '미청산'으로 빼고 셈.

### EA와 다른 점
- EA는 **1분봉**으로 MSS·OB를 보고, 이 스크립트는 **15분봉**(지시대로). 그래서 MSS 선·OB 위치가 EA 알림과 다를 수 있어요.
- EA는 C2 마감을 기다리지 않아요. 이 스크립트 기본은 C2 마감 확인 후 주문(`--c2-close ignore`가 EA와 같은 방식).
- EA 진입은 'OB 도달 → 확인 캔들 마감' 알림이고, 여기는 지정가(A/B/C). EA의 "OB를 몸통으로 뚫고 마감하면 무효", "8시간 감시" 규칙은 안 넣음(대신 4시간 유효).
- EA는 아시아 시간의 '알림'만 막고, 여기는 아시아에 시작한 C2를 통째로 뺌. 아시아장 체결도 빼려면 `--block-asia-fill`.
- S3(같은 높이 저점), T2~T4 목표는 EA에 없음(새 후보 규칙).
