# Venus 모델 v1 — 규칙 명세 (EA와 백테스터가 똑같이 따라야 하는 단일 기준)

근거: `analysis/smc_crt_entries.py`로 FTMO 진입 26건(중복 제외)을 라벨링한 결과.
- 추세 방향 진입(4시간 범위 위쪽 절반, 흐름 방향): 13건 12승 +101.7핍
- 되돌림/디스카운트 진입: 13건 7승 +3.1핍, 평균 역행 2배
- 스윕 후 반전: 2건 2패. CRT(1시간): 3건, 판단 불가
표본이 작으므로 아래 두 모델을 **같은 조건으로 백테스트해 데이터로 고른다.**

## 공통
- 종목 EURUSD, 신호 타임프레임 M15. 신호는 **봉 마감 시** 판단하고 **다음 봉 시가**에 진입.
- 시간은 **IC마켓 서버 시각**(= 뉴욕 시각 + 7시간, 서머타임 자동 반영).
- pip = 0.0001.
- 진입 가능 시간(서버 시각, 신호 봉 마감 시각 기준):
  - 런던: 10:00 이상 13:00 미만 (뉴욕 03:00–06:00)
  - 뉴욕: 15:00 이상 17:30 미만 (뉴욕 08:00–10:30)
- 강제 청산: 서버 19:00 (뉴욕 12:00)에 남은 포지션 시장가 청산.
- 동시 포지션 1개, 하루(서버 날짜) 최대 2회 진입.
- 하루 손실 잠금: 당일 시작 잔고 대비 실현+평가 손실 −3% 도달 시 전부 청산, 그날 진입 금지.
- 리스크: 거래당 잔고의 0.5% (랏 = 위험금액 ÷ (SL핍 × 1랏당 핍가치)), 브로커 최소·단위에 맞춰 내림.
- 백테스트 비용: 봉의 spread(포인트, 10포인트 = 1핍)를 진입 시 반영 + 수수료 랏당 왕복 $7(= 0.7핍).

## 모델 A — 모멘텀 지속 (MC)
롱 조건 (숏은 대칭):
1. 흐름: close[i] − close[i−4] ≥ FlowMin (기본 5핍)
2. BOS: close[i] > 직전 스윙 고점. 스윙 고점 = 신호 봉 이전 16봉(i−16..i−1) 안에서
   high[k] > high[k−1] 이고 high[k] ≥ high[k+1] 인 가장 최근의 k (k ≤ i−1, 이웃 봉 k+1 ≤ i).
3. 위치: (close[i] − 범위저점) ÷ (범위고점 − 범위저점) ≥ 0.5, 범위 = 봉 i−15..i (16봉)의 고점·저점.
SL: 최근 4봉(i−3..i)의 최저가 − 1핍. SL 거리 < 6핍이면 6핍, > 25핍이면 진입하지 않음.
TP: 진입가 + RR × SL거리 (기본 RR 2.0).

## 모델 B — CRT(H4) + M15 BOS
- H4 봉: 서버 시각 0,4,8,12,16,20시 시작 (= 뉴욕 17,21,1,5,9,13시).
- 롱 셋업: 마감된 H4 봉 C2가 직전 H4 봉 C1의 저점을 찌르고(C2.low < C1.low) C1 범위 안에서 마감
  (C1.low < C2.close < C1.high).
- 진입: 다음 H4 봉(C3) 동안, 진입 가능 시간 안에서 M15 BOS(모델 A의 2번 정의) 발생 시 다음 봉 시가.
- SL: C2.low − 1핍. SL 거리 < 6핍이면 6핍, > 30핍이면 진입하지 않음.
- TP: C1.high. (TP거리 ÷ SL거리) < 1.5면 진입하지 않음.
- 셋업은 C3가 끝나면 소멸. 숏은 대칭(C2.high > C1.high, C1 범위 안 마감 → TP = C1.low).

## 검증 절차
- 데이터: MT5 IC마켓 EURUSD M15(필요시 M5), 2019-01 ~ 현재 (`mt5/export_data.py`).
- 학습 구간 IS: 2019-01-01 ~ 2023-12-31. 검증 구간 OOS: 2024-01-01 ~ 현재.
- IS에서만 조정하는 값: FlowMin ∈ {3,5,8}, RR ∈ {1.5,2.0,2.5}. 나머지는 고정.
- IS에서 고른 값 하나로 OOS를 **한 번만** 돌린다. OOS 결과를 보고 다시 고치지 않는다.
- 합격 기준(OOS): 거래 ≥ 60건, 프로핏 팩터 ≥ 1.2, 최대 낙폭 ≤ 10R, 반기별로 손실 구간이 절반 이하.
- 합격하면 데모 계좌 4주 실전(전진) 테스트 → 백테스트와 비교 → 실계좌.
