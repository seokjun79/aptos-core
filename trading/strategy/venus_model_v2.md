# Venus 모델 v2 — 세션 돌파 후보 묶음 (v1 불합격 후 재설계)

v1 결과(`backtest/runs/2026-10-21_v1_icmarkets.md`): A는 하루 1~2회 진입으로 비용만 내고 본전, B(CRT)는 손실.
고객님 기록에서 강했던 것은 **A+ = 직전 4시간 고점·저점 돌파 + 최근 1시간 흐름 (7승 0패)**, 시간대는 KST 18:40~23:30.
v2는 "큰 레벨 돌파 때만, 하루 1번, 가까운 목표"로 좁힌다.

## 공통 (v1 공통 규칙을 그대로 쓰되 아래만 다름)
- 하루(서버 날짜) 최대 1회 진입. 같은 날 같은 후보의 신호는 첫 번째만.
- SL: 신호 봉 포함 최근 4봉의 반대쪽 극값 ∓ 1핍. 6핍 미만이면 6핍, 25핍 초과면 진입 안 함.
- TP: RR × SL, RR ∈ {1.0, 1.5, 2.0}.
- 추세 필터(옵션 T): 신호 봉 마감 시 H1 종가가 H1 EMA50 위(롱)/아래(숏)일 때만. T ∈ {꺼짐, 켜짐}.
- 강제 청산 서버 19:00, 하루 손실 잠금 −3%, 위험 0.5%, 비용(스프레드+$7/랏) 동일.
- 서버 시각 = 뉴욕 + 7시간.

## 후보
- **C1 아시아 박스 돌파 (런던):** 박스 = 당일 서버 02:00~09:00 봉들의 고점·저점.
  진입 창 서버 10:00~13:00. M15 종가가 박스 고점 위(롱)/저점 아래(숏)로 처음 마감한 봉이 신호.
- **C2 4시간 고저 돌파 + 흐름 (A+ 재현):** 진입 창 서버 12:30~17:30 (KST 18:30~23:30, 서머타임 기준).
  신호 = close[i] > max(high[i−16..i−1]) 그리고 close[i] − close[i−4] ≥ 5핍 (숏 대칭).
- **C3 런던 범위 돌파 (뉴욕):** 범위 = 당일 서버 09:00~14:00 고점·저점. 진입 창 서버 15:00~17:30.
  M15 종가가 범위 밖으로 처음 마감한 봉이 신호.

## 검증 절차 (v1과 같음, 다중 비교 주의)
- 조합: 후보 3 × RR 3 × 추세필터 2 = 18개. IS에서만 비교해 PF 최고(거래 ≥ 60) 하나를 고른다.
- 고른 하나만 OOS를 한 번 돌린다. 18개를 비교했으므로 OOS 합격선은 그대로 엄격하게: 거래 ≥ 60, PF ≥ 1.2, 최대 낙폭 ≤ 10R.
- 데이터는 가능한 한 길게(2019년~). MT5 "차트의 최대 바 수"를 무제한으로 바꾼 뒤 다시 내보낸다.
