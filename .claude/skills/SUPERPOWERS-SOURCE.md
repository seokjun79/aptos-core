# superpowers 스킬 출처

아래 6개 스킬은 obra/superpowers (MIT License, 커밋 2ce8aa15d05bd57213e6f746f953aafb7ded7a8b)에서 그대로 가져왔다.

- brainstorming: 아이디어 → 설계 정리
- writing-plans: 작업 계획서 쓰기
- executing-plans: 계획을 단계별로 실행
- verification-before-completion: "끝났다" 말하기 전 확인
- dispatching-parallel-agents: 독립 작업을 여러 에이전트에 동시에 맡기기
- systematic-debugging: 버그 원인부터 찾기
